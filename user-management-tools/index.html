User Management Toolkit

Four standalone tools for mass maintenance on existing Entra ID / Microsoft 365 users — group membership, external invites, password resets, and Job Title / Employee ID updates. None of these create new users; for that, use the User Provisioning Wizard tile.

UserManagementToolkit.zip

All 4 tools, their launchers, and per-tool READMEs — one download.

Download ZIP
What's inside

Add Users To Group

Adds existing users to one or more Entra ID groups — for a group missed during a bulk import.

Invite External Guests

Retroactively invites existing home-tenant users as B2B guests into the external tenant.

Reset User Passwords

Gives existing users each a new, non-identical password — fixes a batch created with one shared password.

Update User Job Info

Mass-updates Job Title and/or Employee ID (with automatic mirroring to Preferred Data Location).

Always launch via the matching Launch-*.bat file — never by double-clicking or running the .ps1 directly, and never via VS Code's F5. Each tool needs STA mode for its sign-in UI, which only the .bat launcher guarantees. Keep each tool's .ps1 and .bat together after unzipping.
